Run these commands from Windows CMD in the project root.

One-time setup after replacing the project files:

    call .venv\Scripts\activate.bat
    python -m pip install -e .

Use the same benchmark, seed, candidate limits, retrieval limit, and Europe PMC
settings for all three runs. Do not pass the old --llm-cache path: the revised
prompts intentionally use a new versioned cache.

1. Fresh raw control

    python -m evaluation.run_document_retrieval --benchmark benchmark/provideq_benchmark.json --num-questions 90 --seed 42 --retriever fusion --query-strategy raw --paperclip-ranking hybrid --europepmc-mode multi --no-europepmc-synonym --paperclip-candidate-limit 30 --europepmc-candidate-limit 30 --retrieval-limit 10 --rrf-k 60 --output-dir outputs\query_fusion_v5 --no-resume

2. Improved HyDE: raw Paperclip + HyDE Paperclip, weighted query fusion; raw Europe PMC

    python -m evaluation.run_document_retrieval --benchmark benchmark/provideq_benchmark.json --num-questions 90 --seed 42 --retriever fusion --query-strategy hyde --paperclip-ranking hybrid --paperclip-query-fusion --query-fusion-rrf-k 10 --reformulated-query-weight 0.5 --europepmc-mode multi --no-europepmc-synonym --no-europepmc-use-reformulated-query --paperclip-candidate-limit 30 --europepmc-candidate-limit 30 --retrieval-limit 10 --rrf-k 60 --output-dir outputs\query_fusion_v5 --no-resume

3. Improved LLM expansion: raw Paperclip + controlled expansion Paperclip, weighted
   query fusion; raw Europe PMC

    python -m evaluation.run_document_retrieval --benchmark benchmark/provideq_benchmark.json --num-questions 90 --seed 42 --retriever fusion --query-strategy llmexpand --paperclip-ranking hybrid --paperclip-query-fusion --query-fusion-rrf-k 10 --reformulated-query-weight 0.5 --europepmc-mode multi --no-europepmc-synonym --no-europepmc-use-reformulated-query --paperclip-candidate-limit 30 --europepmc-candidate-limit 30 --retrieval-limit 10 --rrf-k 60 --output-dir outputs\query_fusion_v5 --no-resume

Expected result folders:

    outputs\query_fusion_v5\fusion_raw_hybrid_multi_nosyn\results.csv
    outputs\query_fusion_v5\fusion_hyde_qfk10_w0p5_hybrid_multi_nosyn\results.csv
    outputs\query_fusion_v5\fusion_llmexpand_qfk10_w0p5_hybrid_multi_nosyn\results.csv

Compare Recall@10 first, then MRR@10 and Recall@5. Also check the warnings column;
source or LLM fallbacks are successful rows but must be disclosed when reporting scores.
If warnings are nonzero after a temporary outage, repeat the same command with
--resume --retry-warnings instead of --no-resume. Only the affected rows will rerun.
