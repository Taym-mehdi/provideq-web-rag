# ProvideQ Web RAG

A modular Web RAG project for biomedical fallback retrieval in ProvideQ.

The goal is to create a transparent, thesis-ready biomedical Web RAG pipeline with:

- query building
- external literature retrieval
- metadata normalization
- evidence snippet extraction
- ranking and reranking
- grounded answer generation
- evaluation support

## Current status

Initial project skeleton with:

- package structure
- configuration
- data models
- text utilities
- CLI smoke test
